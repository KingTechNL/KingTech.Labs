# Portainer

Portainer gives us a simple and clean web interface to manage Docker without memorizing every command. 
In KingTech Labs, we use it for quick visibility into containers, stacks, volumes, and logs across our Docker environments.


## Portainer installation
To make it easier to manage our docker environment, through a web interface, we use Portainer.

Portainer is installed through docker. First we need to create a new docker volume:

```bash
docker volume create portainer_data
```

Now we create (and start) our portainer container:

```bash
docker run -d -p 9000:9000 --name Portainer --restart always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce
```

In some cases it might be desired to disable the servers firewall, this is however at your own risk!
To turn off the firewall in CentOS, execute the following command:

```bash
sudo systemctl stop firewalld
```

Next, to prevent the firewall from turning on after a reboot, we execute the following:

```bash
sudo systemctl disable firewalld
```

Portainer should now reachable on port 9000. Open your web browser and go to `<server-ip>:9000`.

![Portainer](https://res.cloudinary.com/kingtech/image/upload/q_auto/f_auto/v1775413799/Portainer-home_bj6dgn.png)

Select the ‘local’ option and you are done!



## Updating Portainer

As portainer is running directly from docker, we cant use the GUI to run the update. Instead, we need to run the following commands to first remove the existing container and then start a new one:

```bash
docker container stop portainer
docker rm –f portainer
docker run -d -p 8000:8000 -p 9000:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest
```

Note that the final command needs to be identical to the one used in the intitial installation.

Since we mount a volume, and only replace the container, the data should stay intact.

# Hardware

For this server, we used mostly easy to find consumer components. The AMD Ryzen 3800XT packs enough power to run our relatively lightweight services, and 128GB of memory makes sure we can run plenty of virtual machines.

As one of the services is our TrueNAS server, meant for data storage. The server contains 8 hotswap bays for hard drives. Four of which are filled with 4TB Seagate Ironwolf drives. These drives are optimized for NAS systems, meaning they are build for 24/7 operation in setups with multiple drives.

The first iteration of this server used an HP P410 RAID contoller. This allowed us to configure the hard drives in RAID 5 to prevent data loss. However, as this prevented the system from using the SMART functions of the drives, and was hard to maintain. This card was later swapped out for a generic SATA controller card and a ZFS (software) RAID in TrueNAS.

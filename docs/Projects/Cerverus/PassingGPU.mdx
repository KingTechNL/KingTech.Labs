# Passing GPU's

Sometimes a virtual machine requires access to a GPU. 
Due to the nature of hypervisors like Proxmox, Virtual machines dont have direct access to the hardware. 

In order to pass GPU's (or other PCIe devices) to virtual machines properly, we need to make some modifications to our installation:

The steps below are taken from [this website](https://www.reddit.com/r/homelab/comments/b5xpua/the_ultimate_beginners_guide_to_gpu_passthrough/).

## Passing a GPU in Proxmox
First we need to modify our grub configuration in our proxmox shell (ssh or via the web UI).

```bash
nano /etc/default/grub
```

Look for this line: 

```bash
GRUB_CMDLINE_LINUX_DEFAULT="quiet"
```

And modify it to look like one of the lines below (based on the CPU):

```bash
GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on"
GRUB_CMDLINE_LINUX_DEFAULT="quiet amd_iommu=on"
```

We may need to add some additional arguments:

```bash
GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt pcie_acs_override=downstream,multifunction nofb nomodeset video=vesafb:off,efifb:off"
```

Next, we run the following command to apply the changes:

```bash
update-grub
```

After updating our grub configuration, we need to add a few VFIO modules.
Open the /etc/modules file:

```bash
nano /etc/modules
```

And add the following lines:

```bash
vfio
vfio_iommu_type1
vfio_pci
vfio_virqfd
```

Next, run the following 2 commands:

```bash
echo "options vfio_iommu_type1 allow_unsafe_interrupts=1" > /etc/modprobe.d/iommu_unsafe_interrupts.conf

echo "options kvm ignore_msrs=1" > /etc/modprobe.d/kvm.conf
```

We also need to make sure proxmox doesnt use our GPU (it doesnt need it anyway):

```bash
echo "blacklist radeon" >> /etc/modprobe.d/blacklist.conf
echo "blacklist nouveau" >> /etc/modprobe.d/blacklist.conf
echo "blacklist nvidia" >> /etc/modprobe.d/blacklist.conf
```

Now we need to allow passthrough of our GPU. For this, we need to find its PCI adress. The following command will return all pci devices known to the proxmox host:

```bash
lspci -v
```

In the output, we will find 2 entries for our GPU:

```bash
0c:00.0 VGA compatible controller: NVIDIA Corporation GP106GL [Quadro P2000] (rev a1) (prog-if 00 [VGA controller])
0c:00.1 Audio device: NVIDIA Corporation GP106 High Definition Audio Controller (rev a1)
```

Most GPU's show an address for the GPU itself, and an address for the audio bus. We need to remember the first part of the ID, in this case: `0c:00`.

Using the following command, we can retrieve the vendor ID's for our GPU. Note that we use the address we found in the previous step:
`lspci -n -s 0c:00`

In the output, we will now find our GPU's vendor ID. In our case this looks like this:

```bash
0c:00.0 0300: 10de:1c30 (rev a1)
0c:00.1 0403: 10de:10f1 (rev a1)
```

In order to pass the vendor id's to our VM's, we need to add them to proxmox's vfio configuration. Note that we only used the 10de:1c30 and 10de:10f1 parts of the previous output:

```bash
echo "options vfio-pci ids= 10de:1c30, 10de:10f1 disable_vga=1"> /etc/modprobe.d/vfio.conf
```

Finally we run the following commands to apply our changes:

```bash
update-initramfs -u
```

And restart proxmox in order for our changes to take effect.
You should now be able to pass through your GPU in the hardware tab of your virtual machines.

# Hardware

The challenge with this server, is the form factor. We found a very nice small rack mounted case, not much bigger then a network switch, but that meant an extremely small and especially low working height. 

![](https://res.cloudinary.com/kingtech/image/upload/q_auto/f_auto/v1775588445/1_Inter-Tech-IPC-1U-K-125L_md9dg3.jpg)

This case makes the server fit nicely in our rack, where it can cache all services and games in our network. It also makes it very easy to bring along.

The main goal of this server, is to distribute games as fast as possible. Therefor it is fitted with a 10gbps network card. But just a fast network connection isnt enough, the Lexar NM790 solid state drives allow us to cache up to 2 terabyte of installers with 7.400MB/s. The AMD Ryzen 5600G can easily keep up with with these speeds, and serve some game services in the meantime.

![](https://res.cloudinary.com/kingtech/image/upload/q_auto/f_auto/v1776014776/PXL_20260410_134700710_ovglbe.jpg)

Power supplies for 1U racks are not hard to find, though finding one with all required connectors was a bit tricky. We eventually settles on the SilverStone FX350-G. This flex-atx has both the 4-pin CPU connector as the SATA connector that are required for our setup. Unfortunately, the PSU is extremely loud, which is common for these small form factor components.

To make sure the PCIe network card doesnt touch the top of the case, we insulated the lid with kapton tape. 

![](https://res.cloudinary.com/kingtech/image/upload/q_auto/f_auto/v1776014791/PXL_20260410_135428710_igvcpa.jpg)

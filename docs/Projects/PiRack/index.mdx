# Raspberry Pi cluster

![](https://res.cloudinary.com/kingtech/image/upload/q_auto/f_auto/v1776019888/WhatsApp_Image_2026-04-12_at_8.38.32_PM_trhish.jpg)

As an experimental high availability web server, we built a cluster of Raspberry Pi single board computers. These low-cost devices have a small footprint (roughtly the size of a credit card), use very little power but pack quite some processing power.

For this project, we mounted 4 of these devices in a single 1U rack mounted case. Since they use very little power, we can power them over ethernet (PoE). To up the challenge a bit, we mixed different versions with different storage types.

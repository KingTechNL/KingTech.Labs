# Hardware

The pi cluster consists of 4 raspberry pi's, as the pi's are reused from other projects they are not identical.

We use a pi-rack module as an enclosure to mount the raspberry pies in the server rack.
As the Pi's sag a bit, and the top of the server blow is made of metal, we used kapton tape to prevent shorting the pins on the bottom of the pi's.

## Specs

# Boot from SSD

By default, a Raspberry Pi used a micro SD card for its storage. As these cards are not very fast or reliable, the newer Pi 5 (and up) support booting from an NVMe SSD.
To connect an SSD, the Raspberry Pi requires an attachment board.

In our case we used a pimoroni NVMe base, but the steps below should work for any NVMe hat.

In order to boot from an SSD first the firmware needs to be configured and the SSD needs to be flashed.

The following steps come straight from [this website](https://wiki.geekworm.com/NVMe_SSD_boot_with_the_Raspberry_Pi_5) and have been verified to work.


First we create an SD card with `Raspberry Pi OS full with tools` and install this in the Raspberry Pi. The SSD should also be connected to the Pi.

Next, we need to enable PCIe. Open a terminal and run the following command to open a configuration file:

```bash
sudo nano /boot/firmware/config.txt
```

Next, we add the following content to the end of the file:

```bash
# Enable the PCIe External connector.
dtparam=nvme
dtparam=pciex1_gen=3
```
Press `Ctrl-O`, then `enter`, to write the change to the file.
Press `Ctrl-X` to exit nano (the editor).

Now reboot the Pi

```bash
sudo reboot
```

We should now be able to use the **Imager** application on Raspberry Pi OS to install the desired OS on the SSD.

After installing an OS to the SSD, we need to change the boot order of the Pi. 
This is done via the Terminal application on the Raspberry Pi OS again. Open the eeprom (firmware) configuration of the Pi using the following command:

```bash
sudo rpi-eeprom-config --edit
```

Next, we change the `BOOT_ORDER` line to the following:

```bash
BOOT_ORDER=0xf416
```

Hard rebooting the the Pi should now make it boot from the SSD. Remove the SD card, unplug the Pi and plug it back in.

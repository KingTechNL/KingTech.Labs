Since we do not wish to run our experiments on the server we rely on, we created a small scale server rack that is easy to move and store. 

![](https://res.cloudinary.com/kingtech/image/upload/v1780491584/mrack-build-8_qw5t7e.jpg)

The setup consists of a [3D printed mini rack](https://the-diy-life.com/introducing-lab-rax-a-3d-printable-modular-10-rack-system/) containing 3 mini pc's and a network switch.

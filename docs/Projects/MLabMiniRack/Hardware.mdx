# Hardware

![](https://res.cloudinary.com/kingtech/image/upload/v1780491584/mrack-build-5_gfhukc.jpg)

For our MLab server rack, we 3D printed the 10 inch [RabRax mini rack](https://the-diy-life.com/introducing-lab-rax-a-3d-printable-modular-10-rack-system/). This small size racks keeps our test system compact for storage and/or transportation. 

In this rack case, we installed 3 HP Prodesk 400 G3 mini pc's of which we upgraded the memory and storage. The full specs of these systems can be found in the [chapter below](#specs).

To connect these racks, we used a Netgear GS105 gigabit switch. Its small footprint allows us to install something next to it later down the line.

A 10 inch power distribution unit in the back of the rack provides power for the standard HP and Netgear adapters that came with the devices, we plan on upgrading this to something smarter down the line.

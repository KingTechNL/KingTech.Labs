# Hardware

Hardware is where KingTech Labs comes alive. This is the playground where ideas turn into racks, cables, fans, lights, and machines that actually do something.

From enterprise servers to repurposed desktop parts, from Raspberry Pi projects to strange legacy gear we somehow got running again, we love pushing hardware beyond what it was originally built for.

## Servers
Our server setups range from serious rack-mounted systems to creative "this should not work, but it does" builds. We test performance, thermals, reliability, and power use, then share what works and what fails.

You'll find experiments with exotic server hardware, recycled PC parts, and compact Raspberry Pi clusters, all built to host real services for our lab.

## Components
This is where the weird and wonderful parts live: RAID controllers, unusual rack accessories, custom fan mounts, adapters, and all the tiny upgrades that make a big difference.

If it improves airflow, lowers noise, increases uptime, or simply makes the lab more fun to run, it belongs here.

# Overview

Software is where raw hardware turns into a living platform. At KingTech Labs, this is the layer that brings every server, service, and experiment to life.

From hypervisors and storage systems to containers and clustered workloads, we build software stacks that are practical, scalable, and fun to operate.

## Operating systems
Our core stack includes Proxmox, TrueNAS, CentOS, and Photon OS. Each OS has a specific role, and together they form the backbone of our homelab infrastructure.

## Virtualization and containerization
We run mixed workloads using Proxmox, virtual machines, and Docker. This gives us the flexibility to isolate services, test fast, and deploy reliably across different systems.

## Clusterization
For orchestration and high availability, we explore both Kubernetes and Docker Swarm. Clustering lets us move beyond single-host setups and build resilient services that keep running even when one node goes down.

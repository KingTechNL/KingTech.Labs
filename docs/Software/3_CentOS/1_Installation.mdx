# Installation

A pretty detailed description on how to install CentOS 8 (minimal, so without GUI) can be found [here](https://www.howtoforge.com/tutorial/centos-8-minimal-server/).

## Enabling network interfaces
If CentOS does not have its network interface enabled on boot, we need to change the configuration file.
First check which interfaces are available:

```bash
ls /etc/sysconfig/network-scripts/
```

Next, we update the configuration for the interfaces we want enabled on startup (our interface is `ifcfg-ens18`):

```bash
nano /etc/sysconfig/network-scripts/ifcfg-ens18
```

In the file, set `ONBOOT` to `yes`.

# Enabling Docker

Photon comes with docker installed by default, so we just need to enable it. For that we use the following 2 commands:

```bash
systemctl start docker
systemctl enable docker
```

## Install portainer

To allow for easy management of our docker environment through a web interface, we install portainer using docker.

First we need to create a new docker container:

```bash
docker volume create portainer_data
```

Now we create (and start) our portainer container:

```bash
docker run -d -p 9000:9000 --name Portainer --restart always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce
```

Portainer is now reachable on port 9000. Open your web browser and go to `<photon-ip>:9000`.
